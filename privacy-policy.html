Privacy Policy for Jira Sprint Goal Display

Last updated: September 17, 2026

Jira Sprint Goal Display shows the active sprint's name, goal, and days remaining in the header of Jira Cloud Scrum boards. This privacy policy explains how the extension handles data.

Data the extension accesses

When enabled on a Jira Cloud site, the extension accesses the active sprint's name, goal, and end date from the Jira board the user is viewing. It also reads the page structure needed to place the sprint-goal card in the Jira interface.

How data is used

Sprint information is used only to render the sprint-goal card in the current Jira tab. The extension uses the user's existing Jira session to request this information directly from the user's Atlassian site.

Data storage and sharing

The extension does not collect, transmit, sell, rent, share, or transfer sprint information or other user data to the developer or to third parties. Sprint information is processed locally in the browser and is not retained after it is no longer needed to display the card.

The only value stored by the extension is the user's enabled or disabled preference. This setting is stored locally in Chrome using Chrome's extension storage and is not sent to the developer or any third party.

Authentication

The extension does not collect, store, or transmit passwords, API tokens, or other authentication credentials. It uses the existing authenticated Jira session in the user's browser only to request sprint data from that user's Jira site.

Changes to this policy

This policy may be updated when the extension changes. The latest version will be available at this page, with its update date shown above.

Contact

For privacy questions, contact the developer through the support contact listed on the Chrome Web Store page for Jira Sprint Goal Display.
